College Event Scheduling

Paste rooms, equipment, and events in the simple formats below, then solve and watch the timetable fill in.

How the logic works & where the code is

Problem

Assign every event a room + start time so nothing clashes:

  • Room — two events cannot share a room in overlapping hours
  • Equipment — total demand ≤ stock in every hour
  • Organiser — one club/faculty cannot run two events at once
  • Fit — room type must match, capacity ≥ attendees

Backtracking steps

  1. Pick an unscheduled event (plain order, or MRV = fewest options first)
  2. List legal (room, start) choices via options() + ok()
  3. place(..., true) — try one choice and update busy state
  4. Recurse on remaining events with solve()
  5. If stuck: place(..., false) — undo and try the next choice
  6. If no events left → success; if no choices work → fail that branch
solve(pending): if pending empty → SUCCESS pick event e for each (room, start) in options(e): place(e) # TRY if solve(rest): return SUCCESS undo place(e) # BACKTRACK return FAIL

File structure

event_scheduler.py — original Python version (same logic)
app.js — input parsing, timetable UI, buttons only
index.html — page layout & styles
